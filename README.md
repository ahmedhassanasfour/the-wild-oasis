# The Wild Oasis 🏕️

The Wild Oasis is a hotel management dashboard built with React.
It allows staff to manage cabins, bookings, guests, and daily operations efficiently through a modern and responsive interface.

## 🚀 Features

* Authentication and protected routes
* Dashboard with statistics and charts
* Cabin management (create, edit, delete)
* Booking management
* Guest information
* Check-in and check-out system
* Dark mode support
* Responsive UI

## 🛠️ Built With

* React
* React Router
* Styled Components
* React Query
* Supabase
* Recharts

## 📊 Dashboard

The dashboard provides an overview of:

* Recent bookings
* Daily sales
* Occupancy rate
* Check-ins and check-outs

## ⚙️ Installation

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

## 📦 Build

To build the project for production:

```bash
npm run build
```
